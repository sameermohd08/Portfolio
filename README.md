# Mohd Sameer — Portfolio (static site)

This is a simple single-page portfolio generated from the provided resume.

Files:
- index.html
- styles.css
- resume.pdf — included in the repository root so the Download button works.

To view locally
1. Put these files in a folder and open `index.html` in a browser.

Deploy to GitHub Pages
1. Confirm 'Custom domain' in Settings → Pages is empty (we removed CNAME). The project site will be available at `https://sameermohd08.github.io/Portfolio`.
