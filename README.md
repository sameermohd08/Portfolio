# Mohd Sameer — Portfolio (static site)

This is a simple single-page portfolio generated from the provided resume.

Files:
- index.html
- styles.css
- (optional) resume.pdf — place your PDF resume at the repository root so the Download button works.

To view locally
1. Put these files in a folder and open `index.html` in a browser.

Deploy to GitHub Pages
1. Create a repository (e.g., `sameermohd08/portfolio`) and push these files to the default branch.
2. In the repo Settings → Pages, set the source to the default branch and root.
3. Wait a minute — your site will be available at `https://sameermohd08.github.io/portfolio`.
